隐私政策

生效日期：2026 年 10 月 25 日 版本：1.0

句栖是一款本地优先的记录与回看工具。你的句子、备注和旧事默认只保存在这台设备上；句栖没有账号系统，不投放广告，不做用户画像，也不把句库上传到我们的服务器。只有在你自己启用 AI 功能并主动生成时，句栖才会把完成该次生成所必需的内容发送到你配置的 AI 服务端点。

一句话摘要
  • 句子、备注、旧事、设置：本地加密保存，不上传。
  • AI：你开启并主动生成时，才发送当次所需内容；端点由你填写。
  • 备份：由你主动导出加密文件，保存在你选择的位置。
  • 通知：本地系统提醒，不经过服务器。
  • 没有账号、广告、统计 SDK 或云同步。

1. 适用范围与运营者

本政策适用于 HarmonyOS 应用「句栖」（包名 com.juxia.app，以下简称“句栖”或“本应用”）。 运营者为「句栖开发者」（以下简称“我们”）。本政策说明我们如何处理与你有关的信息，以及你如何控制这些信息。

句栖没有登录、注册、云同步或社交功能。你不需要提供姓名、手机号、邮箱或任何账号信息即可使用核心功能。

2. 我们处理哪些信息

句栖只处理你主动输入或在本应用内产生的以下信息：

类别内容用途
你写下的内容 句子、鼓励、旧事、备注、归档注脚、标签/分类、绑定关系 展示、检索、回看、归档与提醒
句库与材料 你手动加入或导入的句子、材料文本、材料文件名与本地路径 抽取、检索与展示
使用状态 首次使用时间、打开天数、上次备份时间、当日心情等本地状态 计算“相伴天数”、备份提醒与当日界面
设置 主题、字体、皮肤、启动文案、提醒开关、AI 端点/模型/风格等 保持你的使用偏好
AI 配置 你填写的 AI 服务地址、模型名、风格；API Key 调用你选择的 AI 服务

API Key 保存在 HarmonyOS 系统级 Asset Store 中；句栖不会把你的 API Key 写入普通配置文件，也不会把它包含在备份里。

3. AI 功能与第三方端点

AI 功能默认关闭，只有你在设置中开启并主动点击生成时才会触发。

触发时，句栖会把完成该次生成所必需的内容发送到你自己填写的 AI 服务端点，通常包括：

  • 当前句子或关键词；
  • 当前所选书目/分类；
  • 当时的心情；
  • 你在界面上编辑后的提示词；
  • 为完成请求所需的技术参数（如模型名、风格）。

句栖不会为了 AI 生成而上传你的完整句库、材料全文、备注集合或备份文件。

该 AI 端点由你自行选择并填写，可能是第三方服务。你发送到该端点的内容，适用该服务提供者的隐私政策与数据处理规则，我们无法控制。请只填写你信任的端点，并避免在提示词中放入你不希望离开设备的信息。

如果你关闭 AI 功能，句栖不会发起 AI 网络请求。

4. 备份与导出

备份由你主动发起。句栖会生成一个加密的备份文件，并交由系统文件选择器保存到你指定的位置。

  • 备份文件使用你设置的备份密码加密；请妥善保管密码，遗失后无法恢复。
  • 我们不会收到、上传或托管你的备份文件。
  • 备份文件保存在哪里、保留多久、是否分享给他人，由你决定。
  • 完整备份可能包含材料文件；纯数据备份只包含文本与设置，不包含材料文件本体。
  • 如果你选择“复制备份”，加密后的备份内容会写入系统剪贴板。剪贴板可能被其他应用读取，请在使用后及时覆盖或清除。

5. 通知与提醒

句栖的“轻轻回访”使用 HarmonyOS 本地提醒能力。提醒的标题、内容和时间在你的设备上生成，不经过我们的服务器。

你可以在应用内关闭提醒，也可以在系统设置中关闭句栖的通知权限。关闭后，句栖不会继续安排新的提醒。

6. 系统权限

权限用途是否必需
网络（INTERNET） 仅在你启用 AI 并主动生成时，访问你填写的 AI 端点 否；不使用 AI 时可不授予或关闭网络
通知/提醒 发送你设置的本地回访提醒 否；可拒绝或随时关闭

7. 存储位置与保存期限

你的句子、备注、旧事、材料索引与设置保存在本机的加密数据库中。句栖不会把它们上传到我们的服务器。

保存期限由你控制：数据会一直保存在本机，直到你：

  • 在应用内删除对应内容；
  • 使用“清空数据”功能；
  • 卸载句栖；或
  • 删除你导出的备份文件。

卸载应用会移除应用私有目录中的数据；已导出到其他位置的备份文件不会被自动删除，需要你自行处理。

8. 共享、转让与公开披露

我们不会出售你的个人信息。除以下情形外，我们不会主动共享或公开你的信息：

  • 你主动使用 AI：当次所需内容会发送到你填写的端点，由该端点提供者处理；
  • 你主动导出/分享：你通过系统分享或文件选择器把备份文件交给其他应用或他人；
  • 法律要求：法律法规、司法或行政机关依法要求时。

句栖不包含广告 SDK、统计 SDK、推送服务 SDK 或社交登录 SDK。除 HarmonyOS 系统能力与你自行配置的 AI 端点外，不接入其他第三方 SDK。

9. 安全措施

  • 本地数据库使用系统提供的加密能力；
  • AI API Key 存放在系统 Asset Store，不写入普通配置；
  • 备份文件使用你设置的密码加密；
  • 应用不申请广泛存储权限，备份通过系统文件选择器完成。

请理解：没有任何技术能保证绝对安全。设备丢失、系统被攻破、你把备份密码或 API Key 告知他人，都可能导致信息泄露。

10. 你的权利

由于数据主要保存在本机，你可以直接通过应用行使以下权利：

  • 查看与复制：在应用内查看内容，或导出备份；
  • 更正：直接编辑句子、备注与设置；
  • 删除：删除单条内容，或清空全部数据；
  • 撤回同意：关闭 AI、关闭提醒，或卸载应用；
  • 投诉与咨询：通过下方邮箱联系我们。

11. 未成年人

句栖不面向 14 周岁以下的儿童单独提供服务。若你是未成年人，请在监护人同意和指导下使用。若你认为我们无意中处理了儿童的个人信息，请联系我们，我们会协助删除。

12. 政策更新

当功能、权限或数据处理方式发生变化时，我们可能更新本政策，并在本页面标注新的生效日期。重大变化会在应用内以适当方式提示。
